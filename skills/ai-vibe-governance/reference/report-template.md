## 明细条目格式（每项）

### 编号 · 现象（人话）
- **等级**：严重（P0）/ 一般（P1）/ 建议（P2）
- **类别**：计算错误 / 链路断裂 / 状态丢失 / 安全向量 / 反馈缺失 / 一致性 / 整洁度
- **位置**：`文件:行号`（可查证）
- **现象**：用用户能懂的语言描述"做了什么 → 发生了什么"
- **根因**：简要，AI 为什么这么写（为什么容易反复犯）
- **复现**：可执行的操作序列
- **期望 vs 实际**：应该怎样 / 实际怎样

### 示例
**S1 · 同一生辰跨页结论打架**
- **等级**：严重（计算错误，不报错）
- **位置**：`snapshot.html:238`；`hub.html:160`；`js/common.js:56`
- **现象**：同一个出生信息（1988-5-20 10:30 北京），快照页说"缺 水"，中枢页说"缺 金"，用户不知道该信哪个
- **根因**：快照页用钟表时、中枢页用真太阳时校正，且计数口径各写各的——AI 每轮各自"写对"，无人做跨页一致性校验
- **复现**：在快照页填上述信息 → 记录结论；打开中枢页 → 记录结论，二者不一致
- **期望 vs 实际**：期望两页一致；实际不同
