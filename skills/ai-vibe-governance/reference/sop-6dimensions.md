# 6 维度 SOP：把"感觉不对劲"翻译成可执行检查项

> 核心价值：人类说"这里不对劲/跳转别扭/点了没反应/状态不对"，Agent 不需要等精准描述，按下面 6 个维度自动拆解检查。

每个维度给：**检查项 → 检查方法（Agent 怎么验证）→ 判定依据（什么算过/不过）**

## A · 跳转链路
| 检查项 | 检查方法 | 判定依据 |
|--------|---------|---------|
| 每个导航/按钮点击后去哪 | Playwright 逐链接点击，记录落地 URL | 落地页真实存在、内容匹配文案 |
| 是否可返回 | 点击后 `goBack()` | 能回到来源页，无白屏 |
| 返回后状态是否保留 | 回退后检查结果区 | 结果仍在或有明确提示，不凭空消失 |
| 死链接/死锚点 | grep `href="#xxx"` 目标 id 是否存在 | 目标锚点存在；不存在即死锚点 |

## B · 返回历史
| 检查项 | 检查方法 | 判定依据 |
|--------|---------|---------|
| 浏览器回退行为 | 走流程后 `goBack()`/`goForward()` | 不白屏、不丢失已生成结果 |
| 站内返回按钮 | 各工具页"← Back" | 回到正确上级页 |
| 面包屑层级 | 对比导航归属 | 面包屑首级 = 该工具的导航分组，非想当然 |
| 三种返回一致性 | 回退/站内返回/面包屑 各走一遍 | 行为一致，不互相矛盾 |

## C · 状态反馈
| 检查项 | 检查方法 | 判定依据 |
|--------|---------|---------|
| 点击有无反馈 | 点击按钮后观察 | 有 toast/加载/结果变化，非静默 |
| 加载/成功/失败/空态 | 触发各状态 | 四态都有可见呈现 |
| toast 是否可见 | 检查 `#toast` 节点存在 + 触发后显示 | 节点存在且内容显示；无节点=静默失效 |
| 假可点元素 | 检查 cursor:pointer 的元素是否有点击行为 | pointer 元素必可点，否则去掉 pointer |

## D · 边界输入
| 检查项 | 检查方法 | 判定依据 |
|--------|---------|---------|
| 空值 | 清空必填项提交 | 友好提示，非静默失败/未捕获异常 |
| 极端值 | 越界年份、非法日期(2/30)、超长文本 | 拦截或明确提示，不静默 rollover |
| 未知项 | "Don't know"复选框/未知时辰 | 有合理默认 + 明确说明 |
| 快速连点 | 连续多次点击提交 | 结果不重复、不双写 |
| 隐私模式 | 禁用 localStorage | 不白屏、有降级提示 |

## E · 多页一致性
| 检查项 | 检查方法 | 判定依据 |
|--------|---------|---------|
| 同一操作不同页面 | 导航/面包屑/按钮跨页对比 | 结构、行为、文案一致 |
| 导航高亮 | 各页高亮组是否匹配当前页归属 | 高亮组 = 真实归属，无漂移 |
| 菜单项完整性 | 各页下拉菜单链接集合对比 | 集合一致（缺项即缺陷） |
| 术语统一 | 同一概念跨页表述 | 英文/中文/拼音用法统一 |

## F · 刷新恢复
| 检查项 | 检查方法 | 判定依据 |
|--------|---------|---------|
| F5 后结果 | 生成结果后 reload | 结果恢复或有安全重来提示 |
| 会话恢复 | 跳走再返回 | 状态不丢 |
| 各工具一致性 | 多工具同测 | 恢复能力一致，不能有的能有的不能 |

## 判定通用原则
- 违反底线行为（点了没反应/结果丢失/静默出错）= 缺陷，无论当初为什么这么写
- 无反馈 = 视为异常（除非有明确设计说明）
- 跨页不一致 = 缺陷（AI 脑补行为，无真实边界测试）
